# Sienna `8965B4512000` (China-market EPS)

> **Scope:** This is the calibration analyzed in this repository.
>
> **Document type:** variant record
>
> **Status:** active
>
> **Evidence grade:** verified (for this calibration only)

## Identity

- **Firmware:** `8965B4512000`
- **MCU:** RH850/P1M-E `R7F701381` (1 MiB CodeFlash + 32 KiB DataFlash)
- **Image:** `RH850_P1M-E_Firmware.bin` (`0x108000` bytes, two flash regions)

## What is established

The firmware-static findings in this repository's ledger are scoped to this
calibration (the `ARCH-`/`SEC-`/`DIAG-`/`SECOC-`/`STORE-`/`COM-` IDs). The
`VAR-` IDs are Corolla-scoped. See [../status/FINDINGS.md](../status/FINDINGS.md)
for the canonical claim/evidence table. The major results:

- Two-region firmware layout; original flat import invalid
  ([../status/CORRECTIONS.md](../status/CORRECTIONS.md) CORR-001).
- Bootloader payload gate fully traced; `SEED_KEY_SECRET` (`0xBFE8`) and
  `PAYLOAD_BUILD_SECRET` (`0xBFD8`) recovered
  ([../security/bootloader-payload-gate.md](../security/bootloader-payload-gate.md)).
- Application SecurityAccess level 2 functional with secret at `0x20840`;
  level 1 is a compiled stub; no configured Dcm security gating in this
  calibration
  ([../security/application-security-access.md](../security/application-security-access.md)).
- SecOC slot-4 state consistent with unprovisioned/default key
  ([../security/secoc/README.md](../security/secoc/README.md)).
- Full DataFlash map (122 records, triplicate bank + checkpoint ring)
  ([../storage/dataflash.md](../storage/dataflash.md)).

## What is not established (even for Sienna)

- Behavior of a **provisioned** unit (this snapshot is consistent with an
  unprovisioned/default SecOC key state).
- Contents of the protected DataFlash tail (pages 480–511, ICU-S reservation).
- Behavioral understanding of most of the 5,845 recovered functions.
