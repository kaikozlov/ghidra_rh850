# Priorities and report navigation

[PRIORITIES.md](PRIORITIES.md) is the current execution queue.
Conclusions, evidence, and unresolved questions belong in the
[target](../variants/README.md) or [subsystem](../README.md#subsystem-reports)
report. Search them with `tools/know QUERY`.

Use the [evidence model](../OVERVIEW.md#evidence-model) to distinguish source
and confidence. Documentation maintenance follows
[AGENTS.md](../../AGENTS.md#writing-it-down).
