MEMORY COVERAGE
---------------
Local RAM aliases on a 0x20000 period on this silicon, so the 128 KB local + 64 KB
global reads cover the part's whole 192 KB RAM array. DataFlash past 64 KB reads as a
single repeated value. Every main-core-readable region on this module is in this set.

WHAT HAS ALREADY BEEN CHECKED
-----------------------------
All 16 dump files were swept with a sliding 16-byte window against two independent
SecOC sync oracles (984 distinct samples from route a74eba85c97eaf67/00000004--
555953f500, and the 206-sample capture in can_oracle.ndjson). Zero survivors. The
positive control - planting a known key into these same files at these same sizes and
re-running with the owner's own (trip, reset) values - recovers it, so the sweep works.

The three RAM key addresses that hold real keys on a 2023 Sienna (0xFEBE6EC0 SecOC,
0xFEBE6E60 master, 0xFEBF42E0 factory) are all empty on this module across three reads,
on a live RAM capture (24.045 % non-zero bytes).

In the 64 KB DataFlash: 67 "aa aa aa aa" slot markers, of which 27 records carry a
16-byte field with 12 or more distinct byte values. Those fields have never been
identified. The SecOC frame key is measurably absent; nothing here rules out other key
material in those 27 records.

The 1,232 oracle rows are all bus 0 and bus 2, none on bus 1 where this EPS answers.
The current reading is that this EPS is not a SecOC participant for steering on this
car, which is why no steering key is stored in it.
